CUDA-Q Logical by Example

The numbered Python programs and steane_bell_e2e_workflow.py under preview/logical/examples/ run in the test suite. The top-level sequence uses ordinary CUDA-Q kernels and target stacks; the standalone sequence exposes each CUDA-Q Logical compiler stage directly. The gadget sequence introduces verification and detector error models separately: start with one authored gadget, then build a physical surface-code memory experiment.

For one computation across both routes, follow the Steane Bell-pair walkthrough.

Standalone compiler examples

Examples 00–03 introduce authoring, placement, code and gadget definitions, and physical scheduling. Continue with encoded execution (06), or factory protocols and evaluation (07–08). Example 09 combines synthesis, factory provisioning, estimation, and scheduling in a lookup-addition capstone.
