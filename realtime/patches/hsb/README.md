# HSB patches

Patches to the Holoscan Sensor Bridge (HSB) source that CUDA-Q Realtime needs
before HSB releases them. `cudaq_realtime_build_hsb` in
`realtime/scripts/deps_common.sh` applies every `*.patch` file here, in name
order, to each HSB clone.

There are none at the moment. This file keeps the directory in place for
tools that copy it alongside `realtime/scripts`.
